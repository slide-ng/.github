# Getting help

| you want to                         | go to                                                                                       |
| ----------------------------------- | ------------------------------------------------------------------------------------------- |
| learn how something works           | the [documentation](https://slide-ng.dev/)                              |
| ask a question or share an idea     | [Discussions](https://github.com/orgs/slide-ng/discussions)                                 |
| report a bug                        | open an issue in the repository concerned, with the bug form                                |
| ask for a feature                   | open an issue with the feature form, after searching the existing ones                      |
| report a security problem           | follow [SECURITY.md](SECURITY.md); never use a public issue                                 |
| contribute                          | read [CONTRIBUTING.md](CONTRIBUTING.md)                                                     |

Before you ask, search the documentation and the existing issues and discussions, including closed ones. If you open an issue about a bug, include the smallest `slides.md` that shows it.

The projects are kept up in spare time. Answers can take a few days, and there is no paid support.
